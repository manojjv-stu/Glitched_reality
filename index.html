GLITCHED REALITY

HOW TO PLAY

MOVEMENT

A / ◀ and D / ▶ to move.

JUMP

W / ▲ / SPACE to jump.

INTERACT

E to interact with objects and terminals.

REALITY COMMAND

Type a command into the NOVA console and press EXECUTE (or Enter). Try "reverse gravity" or "freeze enemies".

PAUSE

ESC pauses the game at any time.

IMPORTANT

Every command has a Reality Stability cost. Spend it wisely — at 0% reality collapses.
